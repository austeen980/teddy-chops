# Teddy Chops

A responsive, static landing page for the Teddy Chops food brand. The site uses plain HTML, CSS, and a tiny inline script—no build step or dependencies required.

## Preview locally

Open `index.html` in a browser.

## Publish with Cloudflare Pages

1. In Cloudflare, open **Workers & Pages** and choose **Create application → Pages → Upload assets** (wording may vary).
2. Upload the `index.html` file, or upload a ZIP containing `index.html` at its top level.
3. Deploy. The page is self-contained and does not need a build command.

You can also connect this GitHub repository to Cloudflare Pages. Set the build command to none and the output directory to `/` (the repository root).
